## 🚀 Featured Projects

### 🌫️ [AQI Early Warning System](https://github.com/arpitagwd/AQI_Early_Warning_System)
> 7-day air quality forecasting for 16 Indian cities — because people deserve to *prepare*, not just react

- 🤖 **ML Stack:** XGBoost + Random Forest (category classification) + LSTM (numeric forecasting)
- 📊 **Explainability:** SHAP values to surface which pollutants (PM2.5, NOx) drive each prediction
- 🌐 **Live Data:** OpenWeatherMap API — real-time PM2.5, NO2, CO, SO2, O3 ingestion
- 🚨 **Anomaly Detection:** Rolling Z-score spike detector with Oct–Nov seasonal awareness (Diwali/stubble burning)
- 👨‍⚕️ **Health Advisories:** Automated SAFE/AVOID activity guidance for children, elderly, asthma patients
- 🖥️ **Deployment:** Interactive Streamlit dashboard — forecasts, AQI gauge, SHAP plots, city comparison

`Python` `XGBoost` `LSTM` `SHAP` `Scikit-learn` `Streamlit` `OpenWeatherMap API`
